# tangential-frantic
* SANCSOFT GAME JAM 2026
* A top down shooter
* Initially planned to be a resource gathering rouge-lite similar to moonlighter where you manage a night club
* Ran out of time but got something close to what we wanted. Wanted Co-op and networking took a long time
  
* ## Instructions
* mouse to aim/shoot
* e to interact
* r to reload if you run out of ammo.
* enemies should drop loot
* reach the exit of the dungeon
